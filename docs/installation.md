# Installation

## Prerequisites

- Node.js 22 and npm, for building. (Runtime installation on a browser does not need Node.)
- An existing Open WebUI server reachable over HTTP(S). The extension connects to servers; it does not install or run Open WebUI.

## Build from source

From the repository root:

```bash
npm install
npm run build
```

`npm run build` cleans `dist/`, builds both targets, and verifies the generated manifests and referenced files. On success you will have:

```text
dist/chromium/   Chromium-family build (Manifest V3, side panel)
dist/firefox/    Firefox build (Manifest V3, sidebar)
```

Both `dist/chromium/manifest.json` and `dist/firefox/manifest.json` are generated by the build; `dist/` is git-ignored and must never be committed.

Optional quality gate before installing:

```bash
npm run validate
```

## Install in a Chromium-family browser (Chrome, Edge, Brave, and similar)

1. Open the extensions page:
   - Chrome/Edge/Brave: navigate to `chrome://extensions` (or `edge://extensions`, `brave://extensions`).
2. Enable **Developer mode** (toggle, usually top-right).
3. Click **Load unpacked**.
4. Select the `dist/chromium` directory from this repository.
5. Pin the "Open WebUI" action from the toolbar puzzle-piece menu.
6. Click the toolbar icon to open the side panel. If the side panel is unavailable, the extension opens its fallback tab instead — this is expected behavior, not an error.

Chromium 114+ is required for the native side panel surface.

## Install in Firefox

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…**.
3. Select `dist/firefox/manifest.json`.
4. Open the Firefox sidebar (View → Sidebar or the sidebar button) and choose **Open WebUI**.

Notes for Firefox:

- Temporary add-ons are removed when Firefox closes; repeat the steps after a restart. This is a Firefox limitation for unsigned extensions, not an extension bug.
- Firefox 109+ is required (`strict_min_version: "109.0"` is declared in the manifest).
- The toolbar action opens the sidebar; if sidebar opening fails, the extension-tab fallback opens instead.

## First-run setup

1. Click the ⚙ (Settings) button in the panel to open the settings page.
2. Add a connection: a display name and your Open WebUI server URL (for example `https://chat.example.com` or `http://localhost:3000`). Only HTTP and HTTPS URLs are accepted; URLs with embedded credentials are rejected.
3. Use **Test connection** in the panel to verify reachability.
4. The embedded server appears in the panel. If the server blocks iframe embedding, use **Open in tab**.

## Permissions during use

The extension installs with minimal permissions. The first time you use a feature that needs more, the browser asks:

| Feature                               | Permission requested        |
| ------------------------------------- | --------------------------- |
| Stage open tabs / tab groups          | `tabs`                      |
| Read current page, selection, or HTML | `activeTab` and `scripting` |
| Read clipboard text                   | `clipboardRead`             |
| Capture visible tab screenshot        | `activeTab`                 |

Denying a permission is safe: the action reports an error and nothing is collected. You can review or revoke these permissions later in the browser's extension permission settings or from the extension's settings page.

## Verify the installation

- The panel opens (side panel on Chromium, sidebar on Firefox, or the fallback tab).
- A configured server loads in the panel or a tab, and **Test connection** reports reachability.
- Context actions appear in the "Context tray" section: Page, Selection, HTML, Clipboard, Tabs, Tab groups, Screenshot.
- Nothing is collected until you click one of those actions.
